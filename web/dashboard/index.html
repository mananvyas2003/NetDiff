How to use this dashboard

  1. Choose Before and After entry .kicad_sch files (same project shape).
  2. Click Run connectivity diff. Parsing and matching run entirely client-side via WebAssembly.
  3. Review the gate (PASS/FAIL), then browse significant vs cosmetic changes.
  4. Export Markdown for PRs or JSON for tooling. Re-open past runs from History.

What NetDiff reports

  • Component add/remove/modify (values, footprints, lib ids)
  • Net add/remove/rename/merge/split
  • Pin connection moves between nets
  • Cosmetic geometry-only edits suppressed from the gate by default

For git revisions, CI, and multi-sheet checkouts prefer the netdiff CLI. Hierarchical projects need companion sheet files on disk — this dashboard is best for entry-sheet pairs. Prefer a minimal UI? Try the WASM demo.
